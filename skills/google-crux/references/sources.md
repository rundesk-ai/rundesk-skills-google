# Sources

- [CrUX API](https://developer.chrome.com/docs/crux/api) — current endpoint, request and response
  fields, URL and origin scopes, form factors, metric types, collection period, update cadence, and
  quota.
- [CrUX History API](https://developer.chrome.com/docs/crux/history-api) — history endpoint,
  collection-period count, weekly arrays, eligibility markers, and overlapping windows.
- [Using the CrUX History API](https://developer.chrome.com/docs/crux/guides/history-api) — index
  correspondence, page-level history, default and maximum periods, and missing-data examples.
- [CrUX methodology](https://developer.chrome.com/docs/crux/methodology) — population and
  eligibility limits behind any reported value.

These are observed Google contracts, not promises this package creates. Recheck them before
changing an endpoint, metric, field, bound, or interpretation.
